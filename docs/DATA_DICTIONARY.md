# Data dictionary

The canonical `Job` model retains original ID, title, company, source, job/direct-apply URLs, description, location, employment type, posting date, raw source payload, parsed experience and compensation, eligibility/category, score explanation, company verification fields, lifecycle dates, status, and duplicate group ID. `All Jobs` additionally includes user-owned `Application Status`, `Notes`, `Saved Status`, `Application Date`, and `Personal Rating`; the program never overwrites them.

Salary values are published amounts only. `CTC LPA` is only set for explicit LPA/lakh annual strings and `Monthly Stipend INR` only for explicit monthly internship amounts.
